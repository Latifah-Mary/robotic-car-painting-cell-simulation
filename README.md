# Robotic Car Painting Cell Simulation

## Project Overview

This simulation project presents a virtual robotic car painting cell developed as part of a robotics simulation assessment. The simulation demonstrates industrial robot movement, trajectory/path planning for vehicle surface painting, and basic collision checking.

## Project Details

- **Name:** Mary Latifah Nyambu
- **College/Institution:** Kenyatta University
- **Simulation Software:** Visual Components Premium OLP 5.1
- **Robot Selected:** ABB IRB 5500-22A
- **End-Effector:** Paint gun/spray applicator
- **Project Type:** Robotic simulation and trajectory planning

## Objectives

The project aims to:

1. Develop a virtual robotic painting cell containing a vehicle model(Proxy), industrial robot, and painting tool.
2. Create and execute a robot trajectory for painting a vehicle surface.
3. Perform basic collision checking and assess the simulation setup.

## Implementation

The virtual cell was assembled in Visual Components Premium OLP 5.1 using a vehicle model, an ABB IRB 5500-22A robot, and a paint applicator.

A side-painting, Roof-painting, and Rear-painting trajectories were created and executed to demonstrate robot movement around the vehicle. Basic collision checking was also performed.

The paint simulation configuration was explored, however, successful paint deposition was not confirmed. Additional work is required to verify the paint-brush assignment and extend the painting trajectories to other vehicle surfaces.

## Results and Limitations

The simulation demonstrates the virtual cell layout, robot movement, execution of the side-painting trajectory, and basic collision checking.

Further development could include:
- Verifying paint deposition and spray parameters.
- Improving trajectory coverage and checking clearances throughout the robot's movement.
